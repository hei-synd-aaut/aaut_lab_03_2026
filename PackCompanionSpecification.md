## Companion Specification

The ctrlX CORE from Bosch Rexroth supports the standardized OPC UA for PackML (OPC 30050) Companion Specification. By installing the ctrlX OS - OPC UA Server App, you can implement the PackML state machine directly in the controller and map machine data to standard OPC UA types, variables, and methods. 

[OPC UA for PackML – Common Object Model: PackML](https://reference.opcfoundation.org/specs/OPC-30050)
